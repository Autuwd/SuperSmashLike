# 开发路线图

## 里程碑总览

```
Phase 1: 原型验证 (4周)
    ↓
Phase 2: 核心系统 (4周)
    ↓
Phase 3: 内容扩展 (3周)
    ↓
Phase 4: 打磨发布 (3周)
    ↓
         ✅ 毕业设计完成
```

---

## Phase 1：原型验证（第1~4周）

**目标**：一个角色能移动、跳跃、攻击，基本格斗循环可玩

### 第1周：项目初始化 + 框架搭建

| 任务 | 文件 | 产出 |
|------|------|------|
| 创建项目目录结构 | `Assets/_Game/` | 完整代码目录 |
| 安装Input System包 | `Packages/manifest.json` | 已安装 v1.14.2 |
| 配置输入映射 | `_Game/Input/Controls.inputactions` | Move/Jump/Attack/Special/Shield/Grab |
| 游戏管理器 | `_Game/Scripts/Core/GameManager.cs` | 游戏状态管理单例 |
| 游戏设置SO | `_Game/Scripts/Data/GameSettings.cs` | 可配置的游戏规则 |

### 第2周：角色基础控制

| 任务 | 文件 | 产出 |
|------|------|------|
| 角色数据SO | `_Game/Scripts/Data/FighterData.cs` | 角色属性配置 |
| 角色控制器 | `_Game/Scripts/Character/FighterController.cs` | 移动/跳跃/重力 |
| 角色状态机 | `_Game/Scripts/Character/FighterStateMachine.cs` | 状态转换 |
| Animator Controller | `_Game/Animations/FighterAnimator.controller` | 动画驱动 |
| 角色Prefab | `_Game/Prefabs/Fighter.prefab` | 可控制的角色 |

### 第3周：战斗系统

| 任务 | 文件 | 产出 |
|------|------|------|
| Hitbox系统 | `_Game/Scripts/Combat/Hitbox.cs` | 攻击判定框 |
| Hurtbox系统 | `_Game/Scripts/Combat/Hurtbox.cs` | 受击判定框 |
| 伤害计算 | `_Game/Scripts/Combat/DamageSystem.cs` | 百分比累计+击飞公式 |
| 击飞物理 | `_Game/Scripts/Combat/KnockbackSystem.cs` | 击飞轨迹+衰减 |
| 角色1Prototype | 使用 PolygonPrototype 角色 | 可操作的斗士 |

### 第4周：舞台与摄像机

| 任务 | 文件 | 产出 |
|------|------|------|
| 舞台搭建 | `_Game/Prefabs/Stages/BattleArena.prefab` | 平台关卡 |
| BlastZone | `_Game/Scripts/Stage/BlastZone.cs` | 边界检测 |
| 可穿越平台 | `_Game/Scripts/Stage/Platform.cs` | 从下方跳穿 |
| 摄像机控制 | `_Game/Scripts/Managers/CameraManager.cs` | 多目标跟踪 |
| 测试场景 | `_Game/Scenes/BattleTest.unity` | 可对战的场景 |

---

## Phase 2：核心系统（第5~8周）

**目标**：多人对战、完整UI流程、防御/抓取系统

### 第5周：多人支持

| 任务 | 说明 |
|------|------|
| PlayerInput多P | 每个角色挂载PlayerInput，绑定不同设备 |
| 玩家生成管理 | PlayerSpawner：根据连接数生成1~4P |
| 输入冲突处理 | 键盘+手柄混用的按键映射 |

### 第6周：UI系统

| 任务 | 说明 |
|------|------|
| 选人界面 | CharacterSelectUI：角色网格、P1-P4选择确认 |
| HUD | 百分比显示+倒计时+命数 |
| 结算画面 | 排名显示+统计数据+再来一次 |
| 暂停菜单 | 暂停/调整设置/退出 |
| 出招表 | 暂停菜单内可查看当前角色全部招式+输入指令；`InputManager` 补充方向+必杀技组合判定 |

### 第7周：防御与抓取

| 任务 | 说明 |
|------|------|
| 护盾系统 | 生成护盾→消耗耐久→破盾 |
| 完美盾反 | 防御启动4帧内受击→反击 |
| Tech受身 | 撞墙/撞地前按防御→受身 |
| 抓取/投技 | 抓取→挣扎→前/后/下/上投 |

### 第8周：游戏规则

| 任务 | 说明 |
|------|------|
| 命数制/时间制 | 两种比赛模式 |
| 暂停逻辑 | 全部暂停/恢复 |
| 比赛流程 | 进入→等待→开始→进行→结算 |

## Phase 3：内容扩展（第9~11周）

**目标**：增加可玩内容，丰富游戏体验

### 第9周：多角色适配

| 任务 | 说明 |
|------|------|
| 为所有FantasyRivals角色配置 | 20个角色×武器绑定 |
| 角色差异化 | 各角色不同的速度/体重/攻击数据 |
| 角色选择画面角色槽 | 增加角色头像和名称 |

### 第10周：多舞台

| 任务 | 说明 |
|------|------|
| Stage1：竞技场 | PolygonFantasyRivals素材搭建 |
| Stage2：森林 | PolygonNatureBiomes素材 |
| Stage3：地牢 | PolygonDungeon素材 |
| Stage4：农场 | SimpleFarm素材 |

### 第11周：道具系统（扩展功能）

| 任务 | 说明 |
|------|------|
| 道具生成逻辑 | 定时/击杀后生成 |
| 基础道具 | 恢复、加速、增强攻击 |
| 投掷道具 | 可捡起+投掷的物体 |
| 特效配对 | 用已有PolygonParticleFX |

---

## Phase 4：打磨发布（第12~14周）

**目标**：Bug修复、性能优化、论文撰写

### 第12周：音效与VFX

| 任务 | 说明 |
|------|------|
| 匹配所有攻击特效 | 每个动作都有对应的粒子效果 |
| UI动效 | 选人/结算动画过渡 |
| 屏幕震动 | 重击命中时镜头震动 |
| 慢动作 | 强力击飞时的Hitstop（打击暂停） |

### 第13周：性能优化

| 任务 | 说明 |
|------|------|
| 对象池化全部特效 | 避免运行时Instantiate/Destroy |
| Animator优化 | 减少参数数量 |
| Draw Call合并 | 合并相同材质的物体 |
| 固定时间步长调整 | 保证60fps物理稳定 |

### 第14周：论文与发布

| 任务 | 说明 |
|------|------|
| 撰写毕业设计论文 | 背景/设计/实现/测试/总结 |
| 制作演示视频 | 3~5分钟游戏演示 |
| 打包可执行文件 | Windows Build |
| 编写用户手册 | 操作说明+常见问题 |
