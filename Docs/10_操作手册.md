# 操作手册

---

## 一、启动与运行

在 Unity 中的操作流程：

```
1. 在 Project 窗口打开 _Game/Scenes/ 目录
2. 双击打开 TitleScene（或测试用 BattleTest）
3. 点击 Unity 编辑器的 Play 按钮
4. 开始游戏
```

## 三、游戏模式

### 命数制 (Stock)
- 每位玩家有一定数量的命 (默认3)
- 被击飞出屏幕边界消耗1命
- 命数为0时淘汰
- 最后存活的玩家获胜

### 时间制 (Time)
- 设定比赛时长 (默认5分钟)
- 击杀对手得分 (+1)
- 自己被击杀失分 (-1)
- 时间结束时得分最高者获胜

## 四、进阶技巧

| 技巧 | 操作 | 说明 |
|------|------|------|
| 二段跳 | 空中再按一次跳跃 | 所有角色都有 |
| 空中闪避 | 空中按防御 | 无敌帧回避攻击 |
| 完美盾反 | 防御启动瞬间被击中 | 触发反击硬直 |
| Tech受身 | 撞墙/地前按防御 | 避免倒地硬直 |
| DI (受击方向影响) | 被击飞时推动摇杆 | 影响击飞方向和距离 |
| 爬版边 | 挂在平台边缘时推摇杆 | 从边缘爬上平台 |
| 抓边 | 被击飞飞向平台边缘时 | 自动抓取平台边缘 |
