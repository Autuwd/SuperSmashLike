### 状态枚举

```csharp
public enum FighterState
{
    Idle,       // 地面待机
    Run,        // 地面移动
    Jump,       // 上升段
    Fall,       // 下落段
    Attack,     // 攻击动画播放中
    Hit,        // 受击硬直
    Stun,       // 眩晕状态
    Knockback,  // 击飞飞行中（含 tumble 翻滚状态）
    Shield,     // 防御
    ShieldStun, // 防禦硬直
    Grab,       // 抓取
    Grabbed,    // 被抓取
    Dead,       // 死亡
    FreeMove    // 自由状态（受击后可受击方向影响）
}
```

### 状态转换规则

| 当前状态 | 输入/事件 | 下一状态 | 条件 |
|---------|---------|---------|------|
| Idle | 左摇杆 | Run | 输入>deadzone |
| Idle/任何 | 跳跃按键 | Jump | grounded && 还有跳跃次数 |
| Idle | 攻击按键 | Attack | 无前摇锁定 |
| Idle | 防御按键 | Shield | - |
| Run | 松开方向 | Idle | - |
| Jump/Vertical | 达到最高点 | Fall | velocity.y < 0 |
| Fall | 着陆 | Idle | isGrounded |
| Attack | 动画结束 | Idle | - |
| 任何（非hit/惯性） | 被攻击命中 | Hit/Stun/Knockback | 取决于攻击力度 |
| Knockback | 碰触BlastZone | Dead | - |
| Shield | 松开防御 | Idle | - |

## 二、击飞系统公式

### 核心公式（基于大乱斗Melee/Ultimate逆向工程）

```csharp
public float CalculateKnockbackVelocity(AttackData attack, float targetDamage, float targetWeight)
{
    // 基础击飞速度公式
    // 参考: Smash Bros. 通用公式
    
    float pDamage = Mathf.Min(targetDamage, 999f);   // 当前伤害（上限999%）
    
    // 第一步：计算基础击飞值 (Base Knockback)
    float baseKB = attack.knockbackBase;
    
    // 第二步：计算加成击飞 (Bonus Knockback)
    // 伤害每增加10%，击飞速度增加一定比例
    float bonusKB = (pDamage * 0.1f) + (pDamage * attack.knockbackGrowth * 0.05f);
    
    // 第三步：体重系数 (重量越大越难击飞)
    float weightFactor = 100f / targetWeight;
    
    // 第四步：最终速度计算 (大乱斗标准公式)
    float knockbackSpeed = (baseKB + bonusKB) * weightFactor * 1.4f + 18f;
    
    // 第五步：增长系数缩放
    knockbackSpeed *= (attack.knockbackGrowth / 100f);
    
    return knockbackSpeed;
}
```

### 击飞角度计算

```csharp
// 攻击命中时，根据攻击数据和命中位置计算最终击飞方向
public Vector3 CalculateKnockbackDirection(AttackData attack, Vector3 hitDirection)
{
    float angle = attack.knockbackAngle;
    
    // Sakurai角度（Autolink角度）：某些攻击具有特殊角度
    // Sdi/Smash Directional Influence（玩家可通过摇杆影响击飞方向）
    
    Vector3 direction = Quaternion.Euler(0, 0, angle) * (hitDirection.normalized);
    return direction.normalized;
}
```

### 衰减与碰撞

```csharp
// 击飞后的每帧更新
public void UpdateKnockback(FighterController fighter)
{
    // 击飞水平速度衰减（空气阻力）
    fighter.velocity.x *= 0.99f;
    
    // 击飞后当速度低于阈值→进入Fall状态
    if (fighter.currentKnockbackSpeed < 1.5f)
    {
        fighter.SwitchState(FighterState.Fall);
    }
    
    // 撞墙/撞地反弹（tech check）
    if (fighter.collidedWithWall)
    {
        // 受击玩家可在碰墙前按防御键→Tech（受身）
        if (fighter.inputBuffer.HasFlag(InputAction.Shield))
        {
            fighter.PerformTech();
        }
        else
        {
            fighter.velocity *= -0.5f; // 反弹衰减
        }
    }
}
```

## 三、连段系统设计

### 连段窗口

```csharp
[System.Serializable]
public class ComboWindow
{
    public float cancelWindow = 0.2f;    // 取消窗口（秒）
    public float trueComboThreshold = 0.1f; // 真连时间阈值
    
    // 可取消的下一阶段动作列表
    public string[] canCancelInto;       // 下一动作ID列表
    public bool canJumpCancel;           // 是否可跳跃取消
    public bool canSpecialCancel;        // 是否可必杀技取消
}
```

### 连段规则（大乱斗风格）

1. **地面连段（Grounded Combos）**
   - Jab 1（第一下A）→ Jab 2 → Jab 3
   - 轻攻击 → 重攻击（特定取消窗口内）
   - 轻攻击 → Smash攻击（需要蓄力时间，不能直接取消）

2. **空中连段（Aerial Combos）**
   - 空N → 落地 → 地面攻击
   - 空上 → 追击

3. **真连/伪连**
   - 真连（True Combo）：对手无法在连段间隙行动（Hitstun 持续时间 > 连段间隔）
   - 伪连：对手可在间隙中防御/闪避

## 六、摄像机系统

### 多目标跟踪

```csharp
[RequireComponent(typeof(Camera))]
public class CameraManager : MonoBehaviour
{
    public Transform[] targets;          // 所有玩家
    public float smoothTime = 0.2f;      // 平滑跟随
    public float minZoomDistance = 10f;  // 最远距离
    public float maxZoomDistance = 30f;  // 最近距离
    
    void LateUpdate()
    {
        // 1. 计算所有目标的包围盒中心
        Vector3 center = GetTargetsCenter();
        
        // 2. 根据玩家分散程度调整距离
        float spread = GetTargetsSpread();
        float targetDistance = Mathf.Lerp(minZoom, maxZoom, 
                                          Mathf.InverseLerp(0, 50, spread));
        
        // 3. 平滑移动到目标位置
        transform.position = Vector3.SmoothDamp(
            transform.position, 
            center - transform.forward * targetDistance,
            ref velocity, smoothTime);
    }
}
```
