## 第一章：预备知识

### 1.1 什么是 Unity？

Unity 是一个**游戏引擎**——一个专门用来做游戏的大型软件。你可以把它想象成一套"积木"：

| 积木类型 | Unity 中的叫法 | 作用 |
|---------|---------------|------|
| 场景 | **Scene** | 一个关卡/画面，比如标题画面、选人画面、战斗画面 |
| 物体 | **GameObject** | 场景中的每个东西（角色、摄像机、灯光、平台）都是 GameObject |
| 组件 | **Component** | 贴在 GameObject 上的功能模块。比如 `Rigidbody2D`（物理）、`SpriteRenderer`（显示图片）、`Animator`（播放动画） |
| 脚本 | **Script** | 用 C# 代码写的自定义组件，定义物体怎么动、怎么反应 |
| 预制体 | **Prefab** | 做好的 GameObject 模板，可以反复使用（比如做 4 个玩家 Fighter） |
| 资源文件 | **Asset** | 所有文件的总称（图片、模型、声音、脚本、预制体...） |

**关键理解**：一个 GameObject = 空壳子。贴了不同 Component 就有了不同能力。

```
GameObject "Fighter_P1"
├── Component: Transform              (位置/旋转/缩放)
├── Component: SpriteRenderer         (显示角色图片)
├── Component: Rigidbody2D            (物理：重力/碰撞)
├── Component: BoxCollider2D          (碰撞体：别人能碰到你)
├── Component: Animator               (播放动画)
├── Component: FighterController.cs   (自定义代码：控制角色行为)
├── Component: InputManager.cs        (自定义代码：读取玩家输入)
└── Component: PlayerInput            (Unity系统组件：连接手柄/键盘)
```

### 1.2 什么是 C# 脚本？

C# 脚本就是一段代码，告诉 Unity 一个物体应该做什么。每个脚本通常包含三个重要的"魔法方法"：

```csharp
void Awake()    // → 物体诞生的瞬间执行（最先执行）
void Start()    // → 物体诞生后第一帧执行（Awake之后）
void Update()   // → 每一帧执行一次（每秒约60次）
```

**类比**：
- `Awake` = 你出生的瞬间（先剪脐带，再睁眼）
- `Start` = 你睁开眼睛（Awake 之后）
- `Update` = 你的心跳（一直不停）

### 1.3 本项目使用的关键技术

| 技术 | 说明 |
|------|------|
| **Rigidbody2D** | Unity 的 2D 物理引擎，让物体受重力影响、可以被推动、会碰撞 |
| **Collider2D** | 碰撞体，定义物体的"身体范围"。有 Trigger（穿透检测）和普通碰撞两种模式 |
| **Animator** | 动画状态机，控制角色播放什么动画（待机/奔跑/跳跃/攻击） |
| **ScriptableObject** | Unity 的数据文件，把数值从代码里"抽"出来放到文件里，改数值不用改代码 |
| **Input System** | Unity 的新输入系统，统一管理键盘/手柄/触屏的输入 |
| **Object Pooling** | 性能优化技术，提前创建好一批对象循环使用，避免运行时反复创建销毁 |

## 第二章：项目的"世界观"——五层架构

整个项目的代码按照职责分成 5 层，从下往上看：

```
┌──────────────┐
│    UI 层     │  让玩家看到和点击的东西
├──────────────┤
│  管理层      │  控制游戏的流程和规则
├──────────────┤
│  游戏逻辑层  │  角色战斗、物理、状态的核心
├──────────────┤
│  数据配置层  │  所有数字参数（ScriptableObject）
├──────────────┤
│  输入层      │  读取按键/摇杆
└──────────────┘
```

**为什么分层？** 每一层只关心自己的事情。比如：
- 输入层只负责"玩家按了 J 键"，不关心角色会做出什么攻击
- 游戏逻辑层只负责"执行攻击逻辑"，不关心屏幕上怎么显示伤害数字
- UI 层只负责"显示伤害数字"，不关心这个数字怎么算出来的

这样改 UI 不影响战斗，改战斗不影响输入。

### 3.1 最简单的文件：BlastZone.cs（舞台边界）

**文件位置**：`Assets/_Game/Scripts/Stage/BlastZone.cs`

**它在现实世界中的对应**：舞台边缘的"万丈深渊"。角色掉出去就死了。

```csharp
public class BlastZone : MonoBehaviour   // MonoBehaviour = "这是一个可以贴在物体上的组件"
{
    // 标记这个 BlastZone 是朝哪个方向的
    public bool isTop;        // 上边界？
    public bool isBottom;     // 下边界？
    public bool isLeft;       // 左边界？
    public bool isRight;      // 右边界？

    // 触发方法：当别的碰撞体碰到这个 BlastZone 时，Unity 自动调用
    private void OnTriggerEnter2D(Collider2D other)
    {
        // 检查撞进来的是不是角色 (FighterController)
        FighterController fighter = other.GetComponentInParent<FighterController>();
        if (fighter != null && fighter.StateMachine.CurrentState != FighterState.Dead)
        {
            fighter.Kill();    // 角色死亡！
        }
    }
}
```

**💡 关键词解释**：
- `MonoBehaviour`：所有能给 GameObject 贴的"组件"都要继承这个基类
- `OnTriggerEnter2D`：两个 Trigger 碰撞体接触时 Unity 自动调用的方法。你不需要手动调用它
- `GetComponentInParent<T>()`：拿到其他 GameObject 上的某个组件。这里是从碰撞到的物体往上找 FighterController

**📦 你需要创建的 Prefab 结构**：
```
BlastZone_Top (GameObject)
├── BoxCollider2D (isTrigger = ✅)
└── BlastZone.cs (isTop = ✅)
```

### 3.3 Hitbox.cs（攻击判定框）

**文件位置**：`Assets/_Game/Scripts/Combat/Hitbox.cs`

**它在现实世界中的对应**：角色的"拳头/武器"。打到对手时造成伤害。

这个文件很重要，完整注释版：

```csharp
public class Hitbox : MonoBehaviour
{
    public AttackData attackData;               // 这个拳头的攻击数据（伤害多少？击飞多远？）
    public FighterController owner;             // 这个拳头属于谁？

    private Collider2D hitCollider;

    private void Awake()
    {
        hitCollider = GetComponent<Collider2D>();
        hitCollider.enabled = false;             // 默认"藏起来"——拳头收着
    }

    // ★ 由 动画事件(Animation Event) 调用
    // 动画播放到"出拳"那一帧时激活
    public void Activate()
    {
        IsActive = true;
        hitCollider.enabled = true;  // 拳头伸出去！
    }

    // ★ 由 动画事件 调用
    // 动画播放到"收拳"那一帧时停用
    public void Deactivate()
    {
        IsActive = false;
        hitCollider.enabled = false;  // 拳头收回来
    }

    // ★ 当拳头打到东西时 Unity 自动调用
    private void OnTriggerEnter2D(Collider2D other)
    {
        if (!IsActive) return;

        Hurtbox hurtbox = other.GetComponent<Hurtbox>();
        if (hurtbox != null && hurtbox.owner != owner)  // 打到别人了！
        {
            hurtbox.owner.ApplyDamage(attackData, owner);  // 让目标角色扣血+被击飞
        }
    }
}
```

**💡 关键概念：Animation Event（动画事件）**
```
Animator 播放"出拳"动画
    │ 在动画时间轴的某一帧，动画师标记了一个事件
    ▼
Unity 自动调用 Hitbox.Activate()
    │
Hitbox 碰撞体启用，检测是否有 Hurtbox 撞进来
    │
    ▼
有碰撞 → OnTriggerEnter2D → 调用 FighterController.ApplyDamage
没有碰撞 → 动画播完 → Animation Event 调用 Hitbox.Deactivate()
```

### 3.4 ObjectPooler.cs（对象池）

**文件位置**：`Assets/_Game/Scripts/Core/ObjectPooler.cs`

**它在现实世界中的对应**：子弹箱。提前装好一堆子弹，用的时候直接取，打完了收回来擦擦再放回去。避免每次开火都"造一颗新子弹"（反复 Instantiate/Destroy 很费性能）。

**类比理解**：

| 不好的做法 | 好的做法（对象池） |
|-----------|-------------------|
| 每次出拳 → 创建一个特效 → 1秒后销毁 | 提前做好10个特效 → 出拳时取一个显示 → 1秒后隐藏 → 下次复用 |
| 每次射击 → Instantiate → Destroy | 启动时 New 出10个 → Spawn → Despawn → Spawn 循环 |

```csharp

    // 取出：ObjectPooler.Instance.Spawn(特效预制体, 位置, 旋转)
    // 归还：ObjectPooler.Instance.Despawn(特效对象, 延迟多少秒)
    
    public GameObject Spawn(GameObject prefab, Vector3 position, Quaternion rotation)
    {
        // 1. 从池子里拿一个隐藏的对象
        // 2. 放到指定位置
        // 3. 设置为可见 (SetActive(true))
        // 4. 返回这个对象
    }

    public void Despawn(GameObject obj, float delay = 0f)
    {
        // 把对象设为隐藏 (SetActive(false))，等下次再被 Spawn
    }
}
```

```csharp
    // ResumeGame()     → 恢复（Time.timeScale = 1）
```

**💡 关键概念：单例模式**

```csharp
public static GameManager Instance { get; private set; }

private void Awake()
{
    if (Instance != null && Instance != this)
    {
        Destroy(gameObject);  // 如果已经有了，就把自己毁灭
        return;
```

单例 = 整个游戏里**只能有一个**这个类的实例。任何其他代码都可以通过 `GameManager.Instance` 访问它，就像全世界都知道"110 = 报警电话"一样。

### 3.6 FighterStateMachine.cs（角色状态机）

**文件位置**：`Assets/_Game/Scripts/Character/FighterStateMachine.cs`

**它在现实世界中的对应**：角色的"心情"和"行为规则"。站着的时候可以走/跳/攻击，飞在空中时不能走但可以空中攻击，被击飞时不能动只能等落地。

#### 所有状态一览

| 状态 | 含义 | 能做什么 |
|------|------|---------|
| `Idle` | 地面待机 | 可以走/跳/攻击/防御/抓取 |
| `Run` | 地面跑步 | 可以跳/攻击（但不能突然站住，要减速） |
| `Jump` | 上升中 | 可以空中攻击/二段跳 |
| `Fall` | 下落中 | 可以空中攻击/速降 |
| `Attack` | 攻击动画中 | 不能移动（某些攻击可连段取消） |
| `Hit` | 被打中（小硬直） | 不能动，等硬直结束 |
| `Stun` | 眩晕（大硬直） | 完全不能动 |
| `Knockback` | 被击飞（飞在空中） | 只能等速度降下来或撞墙 |
| `Shield` | 举盾防御 | 减伤，消耗护盾耐久 |
| `Grab` | 抓着别人 | 可以投技/松开 |
| `Grabbed` | 被别人抓着 | 可以按键挣扎 |
| `Dead` | 死了 | 什么都做不了 |
| `FreeMove` | 击飞后速度降低 | 可以控制方向（DI）但不能攻击 |

#### 核心方法

```csharp
public bool CanTransitionTo(FighterState target)
{
    // 规则：不是所有状态都能随便转换
    // 比如：死了只能重生(→Idle)，不能直接变成攻击
    // 比如：攻击中可以连段(Attack→Attack允许)
}

public void TransitionTo(FighterState newState)
{
    // 1. 检查 CanTransitionTo → 不让转就不转
    // 2. 记下上一个状态
    // 3. 设置新状态
    // 4. 触发 OnStateChanged 事件

public bool IsInAir()      // 是否在空中？
```

**转换规则实例**：
```
玩家在空中按攻击键
    │
InputManager 调用 fighter.TryAttack(attackData)
    │
FighterController.CheckState() → state.CanAct() == true? 是
    │
→ TransitionTo(FighterState.Attack)
    │
攻击动画播放 → 攻击结束 → TransitionTo(FighterState.Fall) [还在空中]
或 攻击命中 → 落地 → TransitionTo(FighterState.Idle) [已落地]
```

### 3.8 FighterController.cs（角色控制器——项目核心）

**文件位置**：`Assets/_Game/Scripts/Character/FighterController.cs`

```
     └──────────────┘         └──────────────────┘
```

#### 关键方法逐行解读

**① `ApplyDamage()`——"被打"的完整流程**

```csharp
public void ApplyDamage(AttackData attack, FighterController attacker)
{
    // Step 1：无敌检查
    if (isInvincible || StateMachine.CurrentState == FighterState.Dead)
        return;  // 无敌或已死 → 不受伤害

    // Step 2：累加伤害（大乱斗特色：伤害百分比一直涨）
    float finalDamage = attack.damage * GameManager.Instance.gameSettings.damageRatio;
    CurrentDamage += finalDamage;
    OnDamaged?.Invoke(finalDamage, attacker);

    // Step 3：让 DamageSystem 计算击飞速度和方向
    float knockSpeed = DamageSystem.CalculateKnockbackVelocity(
        attack, CurrentDamage, fighterData.weight);
        //           ↑你现在多少伤害  ↑你多重

    Vector2 knockDir = DamageSystem.CalculateKnockbackDirection(
        attack, transform.position - attacker.transform.position);
        //                ↑从攻击者的方向把你打飞

    // Step 4：应用击飞
    ApplyKnockback(knockDir, knockSpeed);
}
```

**② `ApplyKnockback()`——"被击飞"的物理实现**

```csharp
public void ApplyKnockback(Vector2 direction, float speed)
{
    CurrentKnockbackSpeed = speed;
    knockbackVelocity = direction.normalized * speed;  // 击飞速度向量
    isInKnockback = true;

    // 计算硬直时间
    float hitstunDuration = DamageSystem.CalculateHitstun(speed);
    StateMachine.TransitionTo(FighterState.Knockback);

    // 启动协程：硬直结束后可自由移动（DI, Directional Influence）
    StartCoroutine(EndHitstunAfter(hitstunDuration));
}
```

**③ `TryJump()`——跳跃**

```csharp
public void TryJump()
{
    if (!StateMachine.CanAct() || isInKnockback)
        return;  // 不能动或飞行中 → 不能跳

    if (remainingJumps > 0)
    {
        // 一段跳用全力，二段跳弱一点（85%）
        float force = (remainingJumps == fighterData.jumpCount) 
            ? fighterData.jumpForce 
            : fighterData.jumpForce * 0.85f;

        velocity.y = force;
        remainingJumps--;
        StateMachine.TransitionTo(FighterState.Jump);
    }
}
```

**④ `Respawn()`——重生（重置所有状态）**

```csharp
public void Respawn(Vector3 position)
{
    transform.position = position;     // 移到出生点
    CurrentDamage = 0f;                // 伤害归零
    CurrentKnockbackSpeed = 0f;
    knockbackVelocity = Vector2.zero;  // 停止所有物理运动
    velocity = Vector2.zero;
    isInKnockback = false;
    isInvincible = true;               // 重生无敌
    respawnTimer = GameManager.Instance.gameSettings.respawnTime;
    currentShieldHP = GameManager.Instance.gameSettings.shieldMaxHP;  // 满盾
    isShielding = false;
    remainingJumps = fighterData.jumpCount;  // 满跳跃次数

    StateMachine.TransitionTo(FighterState.Idle);
    rb.velocity = Vector2.zero;
}
```

#### Unity Input System 的 3 种工作方式

本项目使用 **Send Messages 模式**：PlayerInput 组件检测到按键后，自动调用 InputManager 上对应名字的方法。

```
    │
```

#### 上下文攻击选择（大乱斗特色）

```csharp
private AttackData GetContextualAttack()
{
    bool isInAir = fighterController.StateMachine.IsInAir();

    // 空中：根据摇杆方向选不同的空中攻击
    if (isInAir)
    {
        if (摇杆上推) → aerialUp (空上)
        if (摇杆下推) → aerialDown (空下)
        if (摇杆左推) → aerialBack (空后)
        if (摇杆右推) → aerialForward (空前)
        if (没推摇杆) → aerialNeutral (空N)
    }

    // 地面：根据摇杆方向选 tilt 或 jab
    if (摇杆上推) → tiltUp (上强)
    if (摇杆下推) → tiltDown (下强)
    if (摇杆左/右推) → tiltSide (横强)
    if (没推摇杆) → jab1 (轻击)
}
```

### 3.10 MatchManager.cs（比赛控制器）

**文件位置**：`Assets/_Game/Scripts/Managers/MatchManager.cs`

**它在现实世界中的对应**：拳击裁判。喊"READY? GO!"，计时，看谁赢了。

```csharp
public class MatchManager : MonoBehaviour
{
    private IEnumerator MatchFlow()
    {
        // 阶段1：倒计时 3 秒
        for (int i = 3; i > 0; i--)
        {
            Debug.Log($"Countdown: {i}");
            yield return new WaitForSeconds(1f);
        }

        // 阶段2：比赛进行
        while (IsMatchActive)
        {
            // 时间制检查
            if (时间到) → EndMatch()

            // 命数制检查
            if (活着的玩家 ≤ 1) → EndMatch(胜者ID)

            yield return null;
        }
    }

    // 重生玩家（BlastZone 触发击杀后调用）
    public void RespawnPlayer(FighterController fighter)
    {
        Transform spawn = GetRandomSpawnPoint();  // 随机出生点
        fighter.Respawn(spawn.position);
    }
}
```

**💡 关键概念：Coroutine（协程）**

```csharp
private IEnumerator MatchFlow()
{
    // → 开始执行
    Debug.Log("3");              // 立即输出
    yield return new WaitForSeconds(1f);  // → 暂停1秒
    Debug.Log("2");              // 1秒后输出
    yield return new WaitForSeconds(1f);  // → 再暂停1秒
    Debug.Log("1");              // 2秒后输出
    yield return new WaitForSeconds(1f);
    Debug.Log("GO!");            // 3秒后输出
}
```

协程 = 能"暂停"再"继续"的函数。`yield return` 就是"我先暂停，下次叫我"。

### 3.11 CameraManager.cs（摄像机）

**文件位置**：`Assets/_Game/Scripts/Managers/CameraManager.cs`

**它在现实世界中的对应**：摄影师。大乱斗的摄像机会自动拉远/拉近，保证所有玩家都在画面里。

**核心逻辑**：
```
1. 计算所有存活玩家的"中心点"
2. 计算玩家之间的"最远距离"
3. 如果距离远 → 拉远摄像机
4. 如果距离近 → 推近摄像机
5. 平滑移动到目标位置
```

**为什么在 LateUpdate 里执行？**
```
Update() → 所有玩家移动完毕
LateUpdate() → 摄像机再移动（此时所有玩家位置已确定）
```

如果摄像机在 Update 里移动，可能追不上刚移动完的角色，画面会抖动。

### 3.13 Platform.cs（可穿越平台）

**文件位置**：`Assets/_Game/Scripts/Stage/Platform.cs`

**它在现实世界中的对应**：大乱斗里那些"可以从下方跳上去"的平台。

**工作原理**：
```
默认状态：
  Platform 的 Collider2D.isTrigger = true
  → 角色从下方可以穿过去
  → 角色站在上面却不会掉下去（因为物理引擎处理 Trigger 碰撞时会停在表面）

按下 ↓ + 跳跃时：
  Platform.DropThrough() 被调用
  → 临时 isTrigger = false（角色会穿过平台）
  → 0.5 秒后自动恢复 isTrigger = true
```

```
  角色站在平台上        角色按下↓+跳         角色穿过平台         平台恢复
  ┌─────────┐        ┌─────────┐           ┌─────────┐        ┌─────────┐
  │  🧑💪    │        │    ↓     │          │         │        │         │
  │═════════│        │═════════│           │   🧑💪  │        │═════════│
  │  平台    │        │  平台    │           │     ║   │        │  平台    │
  │         │        │         │           │     ║   │        │         │
  ↓                 ↓                     ↓                 ↓
  isTrigger=true    isTrigger=false       可以穿过            isTrigger=true
  (角色站在上面)    (开始下落)              (平台恢复)          (恢复正常)
```

## 第六章：常见问题

### Q1：什么是 `?` 和 `?.` 和 `??`？

```csharp
// ? 在类型后面表示"这个值可能是空的"
public System.Action<GameState> OnGameStateChanged;  // 事件
OnGameStateChanged?.Invoke(newState);  // 如果 OnGameStateChanged 不为空，就调用它

// ?? = "如果左边是空，就用右边"
string name = fighterData?.fighterName ?? "Unknown";
// 如果 fighterData 不为空 → name = fighterData.fighterName
// 如果 fighterData 为空 → name = "Unknown"
```

### Q2：`[SerializeField]` 是什么？

```csharp
[SerializeField] private List<FighterController> activePlayers = new();
```

`private` = 别的代码不能直接访问。
`[SerializeField]` = 但 Unity 的 Inspector 中可以拖拽赋值。

### Q3：`=>` 是什么？

```csharp
public int PlayerCount => activePlayers.Count;
```

等价于：
```csharp
public int PlayerCount
{
    get { return activePlayers.Count; }
}
```

叫"箭头表达式"，简化 getter 的写法。

### Q4：为什么有些方法叫 `OnTriggerEnter2D` 而不是我取的名字？

这些是 Unity 的**事件方法**。Unity 会在特定时机自动调用特定名字的方法：

| 方法名 | 触发时机 |
|--------|---------|
| `Awake()` | GameObject 被创建时 |
| `Start()` | GameObject 激活后第一帧 |
| `Update()` | 每帧 |
| `FixedUpdate()` | 每固定时间步长（物理相关） |
| `LateUpdate()` | 所有 Update 执行完后 |
| `OnTriggerEnter2D(Collider2D)` | 碰撞体触碰到 Trigger 时 |
| `OnDestroy()` | GameObject 被销毁时 |
| `OnDrawGizmos()` | Unity 渲染 Scene 视图时 |

你不需要手动调用它们，Unity 会自动调用。

### Q5：GetComponent 是干什么的？

```csharp
FighterController fighter = other.GetComponentInParent<FighterController>();
```

翻译成大白话：**"从这个碰撞到的物体身上，找到 FighterController 这个组件"**

每个 GameObject 可以贴很多组件。`GetComponent<T>()` 就是在问："你身上有没有贴 T 类型的组件？"

如果对方的 GameObject 结构是：
```
对手角色 (GameObject)
├── Rigidbody2D
├── Collider2D
├── Hurtbox.cs ← 我们碰到的是这个
└── FighterController.cs ← 我们想找到这个
```

`GetComponentInParent<FighterController>()` = "从 Hurtbox 往上找，找到兄弟组件 FighterController"
