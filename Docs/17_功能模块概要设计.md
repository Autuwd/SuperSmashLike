# 功能模块概要设计

---

## 一、单人模式模块

### 1. 角色选择

玩家从一个角色列表中挑选自己要使用的斗士，确认后进入下一步。

### 2. 地图选择

选择对战舞台，预览舞台外观，确认后进入规则设置。

### 3. 游戏规则设置

设置比赛规则：模式（命数制/时间制）、具体参数、CPU 难度。

### 4. 游戏内战斗

核心玩法：玩家操控角色与 CPU 对手在舞台上对战，直到分出胜负。

### 5. 出招表

#### 功能描述

显示当前角色的全部招式列表、输入指令和帧数据，帮助玩家了解角色性能。出招表分为底层输入逻辑和 UI 展示两部分。

#### 输入逻辑（待实现）

`FighterData` 已为每个角色预留 4 个必杀技数据槽（`specialNeutral/side/up/down`），但 `InputManager` 中尚无方向键+必杀技键的组合判定逻辑。需新增：

- **方向+必杀技组合判定** — 类似 `GetContextualAttack()`，根据左摇杆方向和是否空中选择对应的必杀技（必杀N / 横必杀 / 上必杀 / 下必杀）
- **Cancel 到必杀技** — 地面攻击/空中攻击的可取消帧内按必杀技键，自动取消到必杀技（`AttackData` 已有 `canSpecialCancel` 字段）
- **蓄力必杀技** — 按住必杀技键蓄力（参考 Smash 蓄力机制），松开释放增强版

#### UI 展示

- **暂停菜单出招表** — 战斗中按暂停后，可查看当前角色的完整出招表
- **选人界面出招表** — 选中角色后按特定键（如 F1/Help）弹出招式预览
- **训练模式帧数据面板** — 实时显示当前招式的帧数据（已在训练模块中列出）

#### 出招表内容

| 分类 | 招式 | 输入指令 | 说明 |

- 输入指令判定机制与攻击共用 `AttackData`，不需额外数据结构
- 每个角色的 `FighterData` 需填写招式名称和描述，供出招表 UI 读取
- 当前代码中 `InputManager.OnSpecial()` 设置了 `SpecialPressed` 但 **未被 Update 消费**，需补充生成逻辑

## 二、多人游戏模块

### 1. 角色选择

2~4 名玩家使用键盘分区 + 手柄在同一屏幕上对战，每名玩家从角色列表中挑选自己要使用的斗士，全部确认后进入下一步。

### 2. 地图选择

选择对战舞台，预览舞台外观，确认后进入规则设置。

### 3. 游戏规则设置

设置比赛规则：模式（命数制/时间制）、具体参数。

### 4. 单人模式外新增功能

- **多设备识别** — PlayerInputManager 自动检测键盘（P1/P2 分区）+ 手柄（P3/P4），即插即用
- **空位填补 CPU** — 未连接玩家的位置自动填入 AI，可手动切换 玩家/CPU/空位
- **多人独立选人锁定** — 每个玩家在自己的槽位独立高亮、确认、锁定，互不干扰
- **4 人 HUD** — 4 套伤害百分比、头像、命数同时显示在屏幕四角
- **4 人摄像机** — 多目标自适应缩放（已有代码，需调参）
- **4 人生成点** — 4 个 SpawnPoint 自动分配初始位置（已有代码）

## 三、训练模式模块

### 功能描述

无规则限制的练习环境，玩家自由练习操作和连段，提供辅助工具。

### 功能要点

- **无规则战斗** — 禁用命数/时间限制，战斗永不结束
- **重置功能** — 按 R 键将角色和对手复位，伤害归零
- **CPU 开关** — 一键切换对手 AI 开启/关闭（可设静止木桩或移动木桩）
- **帧数据面板** — 实时显示当前攻击的前摇帧、判定帧、后摇帧数
- **按键输入显示** — 屏幕底部显示当前按下的按键，辅助确认输入
- **Hitbox 可视化** — 常开 Hitbox/Hurtbox 碰撞框（已有 Gizmo 代码）
- **慢动作模式** — 按 Shift 切换 0.5 倍速，观察帧细节
- **无敌模式** — 玩家自身无敌，专注练习连段
- **连段计数器** — 显示当前连段 Hit 数
- **DI 模拟** — 设置对手 DI 方向，练习追击确认
- **保存/加载配置** — 存档当前训练设置

## 四、设置以及音效模块

### 1. 按键设置

玩家自定义所有操作的按键映射，支持键盘和手柄。

- **按键重绑定** — 选择操作 → 按下新键 → 绑定
- **冲突检测** — 同一按键绑定多个操作时提示
- **恢复默认** — 一键恢复初始键位
- **多设备独立配置** — 键盘 P1、P2、手柄各自独立键位
- **持久化** — 保存到 PlayerPrefs

### 2. 音频设置

- **音量控制** — 总音量 / SFX（音效）/ BGM（背景音乐）三路独立滑块
- **静音开关** — 一键静音
- **音频管理器** — AudioManager 单例，提供 PlaySFX / PlayMusic / StopMusic 接口

### 3. 画面设置

- **分辨率选择** — 1920×1080 / 1600×900 / 1280×720
- **全屏/窗口切换** — 全屏 / 窗口 / 无边框
- **帧率限制** — 60fps / 120fps / 不限制
- **画质预设** — 低 / 中 / 高

### 4. 游戏设置

- **默认规则偏好** — 默认命数/时间/伤害比例
- **默认难度偏好** — CPU 默认难度
- **语言设置** — 预留多语言接口

## 五、结算界面与游戏记录模块

### 1. 结算界面

比赛结束后显示结果排名和统计数据，提供后续操作。

- **"GAME!" 过渡** — 比赛结束时播放动画，1.5 秒后进入结算
- **排名展示** — 1st（金色边框+胜利动画）→ 4th（灰色）
- **统计数据** — 击杀数、受伤总量、最大连击、受身次数、盾反次数
- **再来一局** — 保留角色/地图/规则配置，重新加载战斗
- **返回主菜单** — 回到标题画面

### 2. 游戏记录

保存历史比赛结果，支持查看过往战绩。

- **记录保存** — 每局结束后自动保存到本地 JSON 文件
- **历史列表** — 显示最近 50 场比赛记录
- **记录详情** — 点击查看单局的完整统计数据
- **胜率统计** — 总场次 / 胜场 / 胜率
- **角色使用统计** — 各角色使用次数和胜率
- **清空记录** — 一键删除所有历史记录
