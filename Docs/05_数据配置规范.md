# 数据配置规范

本文档定义项目中所有 ScriptableObject 数据的结构和配置规范。

---

## 一、FighterData — 角色数据

### 配置路径
`Assets/_Game/ScriptableObjects/Characters/`

### 数据字段说明

```csharp
// 示例：创建一个 RedDemon 角色数据
// 在 Unity Editor 中: 右键 → Create → SuperSmashLike → Fighter Data

字段名                 推荐值(RedDemon)    说明
─────────────────────────────────────────────────────
角色名称                Red Demon          显示名称
体重(Weight)           105                 越大越难击飞 (范围: 80~150)
行走速度(WalkSpeed)     4.5                地面行走 (范围: 3~7)
冲刺速度(RunSpeed)      7.5                地面冲刺 (范围: 5~11)
空中速度(AirSpeed)      5.0                空中水平速度 (范围: 3~8)
跳跃力(JumpForce)       11.0               初始跳跃速度 (范围: 8~15)
二段跳跃力             8.5                第二段跳跃 (范围: 6~12)
跳跃次数               2                  通常为2 (某些角色可3段)
空中闪避次数            1                  空中回避 (通常1次)
弹跳重量级             Medium              视觉抖动类型 (Light/Medium/Heavy)
```

## 二、StageData — 舞台数据

### 配置路径
`Assets/_Game/ScriptableObjects/Stages/`

```csharp
字段名           类型       说明
────────────────────────────────
舞台名称          string    显示名称
预制体            GameObject 舞台场景预制体
音乐              AudioClip  背景音乐
平台列表          Platform[] 平台位置和尺寸
摄像机边界        Bounds     X/Y/Z范围限制
屏幕边界距离      float      BlastZone距屏幕边缘距离
光照预设          Color      环境光照颜色
```

## 三、GameSettings — 游戏规则

### 配置路径
`Assets/_Game/ScriptableObjects/GameModes/`

```csharp
字段名                类型       默认值   说明
────────────────────────────────────────────
默认比赛时间           int        300     秒 (0=不限时)
默认命数               int        3       0=无限
默认伤害比例           float      1.0     伤害缩放系数
物品开关               bool[]    全开    各道具启用开关
CPU难度                int        3       1~5
暂停时暂停             bool       true    暂停菜单时游戏暂停
伤害显示模式            enum      百分比  百分比/数值
击飞显示模式            enum      正常    正常/固定/关闭
```

## 四、命名规范

```
文件名格式: [类型]_[名称].asset
类型前缀:
  FD_    FighterData        → FD_RedDemon.asset
  SD_    StageData          → SD_Arena.asset
  GS_    GameSettings       → GS_TimeMatch.asset
  AD_    AttackData         → AD_Jab.asset (保留扩展用)
```

## 五、Prefab命名规范

```
类型前缀:
  Fighter_     → Fighter_RedDemon.prefab
  Stage_       → Stage_Arena.prefab
  FX_          → FX_HitImpact.prefab
  UI_          → UI_HUD.prefab
  Item_        → Item_Health.prefab
```
