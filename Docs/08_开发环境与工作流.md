# 开发环境与工作流

---

## 一、开发环境

| 工具 | 版本 | 用途 |
|------|------|------|
| Unity Editor | 2022.3.62f3 | 主开发环境 |
| Visual Studio 2022 | 最新 | C# 代码编辑 |
| Git | 最新 | 版本控制 |
| GitHub Desktop / Sourcetree | 任意 | Git GUI |
| Unity Addressables | 可选 | 资源管理优化 |

## 二、场景管理

```
场景列表：
├── BootScene              (启动/加载界面)
│   └── 加载完成后跳转
├── TitleScene             (标题画面)
│   └── 按任意键进入
├── CharacterSelectScene   (选人界面)
│   └── 所有玩家锁定后跳转
├── BattleScene            (对战主场景)
│   └── 比赛结束后跳转
└── ResultScene            (结算画面)
    └── 选择再来一局/返回标题
```

## 三、Git 工作流

```
main ─── 稳定版本，只合并经过测试的完成功能
  │
  ├── dev ─── 开发分支，日常开发在此
  │    │
  │    ├── feature/character-system    → 角色系统
  │    ├── feature/combat-system       → 战斗系统
  │    ├── feature/ui-system           → UI系统
  │    ├── feature/stage-design        → 舞台设计
  │    └── fix/*                       → Bug修复
  │
  └── release/v1.0 ─── 发布版本分支
```

## 四、每日开发流程

```
1. git pull → 获取最新代码
2. 在 Unity 中打开项目
3. 完成今日计划内容
4. Compile → 确保无编译错误
5. Run in Editor → 功能验证
6. git commit → 提交 (含清晰的commit message)
7. git push → 推送到远程
```

## 五、调试技巧

### Unity Debug 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+P | 播放/暂停 |
| Ctrl+Shift+P | 逐帧播放 |
| F9 | 添加断点 (VS attach) |
| F12 | 跳转到定义 |
