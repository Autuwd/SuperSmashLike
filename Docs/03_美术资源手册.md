| 角色 | 特点 | 建议用途 |

## 二、动画资源 (Animations)

| 分类 | 动画文件 | 大乱斗对应动作 | 备注 |

| | `A_Idle_Menacing01_*` | 挑衅动作 | 按挑衅键播放 |
| **移动** | `A_Sprint_F_Masc` (Sample) | 冲刺 | Samples目录 |
| **攻击-轻** | `A_Attack_LightCombo01A/B/C_*` | 地面连续A | 3段轻击 |
| | `A_Attack_LightFencing01_*` | 横A戳击 | 远距离轻击 |
| | `A_Attack_LightLeaping01_*` | 空中攻击 | 分水平/垂直版本 |
| **攻击-重** | `A_Attack_HeavyCombo01A/B/C_*` | 地面强攻击 | 3段重击 |
