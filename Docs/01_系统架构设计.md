## 二、核心系统职责分解

### 2.1 输入层 (Input)

| 组件 | 职责 |
|------|------|
| `PlayerInput` (Unity组件) | 接收键盘/手柄输入，派发到对应Action |
| `InputActionAsset` | 定义所有操作映射（Move/Jump/Attack/Special/Shield/Grab/Pause） |
| `InputManager` | 可选封装层，处理输入历史/缓冲/连段输入检测 |

**输入映射表：**

| 游戏操作 | Keyboard (P1) | Xbox手柄 | PS手柄 | 大乱斗对应 |
|---------|-------------|---------|-------|-----------|
| 移动 (左摇杆) | WASD | Left Stick | Left Stick | 左摇杆移动 |
| 跳跃 | Space / W | A | Cross | 按A跳跃 |
| 普通攻击 | J | X | Square | 按B攻击 |
| 必杀技 | K | B | Circle | 按Y必杀技 |
| 防御 | L | RB / LB | R1 / L1 | 按住ZR/ZL防御 |
| 抓取 | U | RT | R2 | 抓取→投技 |
| Smash攻击 (方向+攻击) | WASD+J | Stick+LK | Stick+Square | 左摇杆+A强攻击 |
| 暂停 | Escape | Start | Options | +键暂停 |

### 2.2 游戏逻辑层 (Gameplay)

#### 角色控制器职责链

```
PlayerInput
    │
    ▼
FighterController（主控制器，每帧Update）
    │
    ├── MovementHandler（移动/跳跃/重力/击飞物理）
    │
    ├── StateMachine（状态转换：Idle/Run/Jump/Fall/Attack/Hit/Stun/Knockback/Dead）
    │
    ├── AttackManager（攻击发起/连段/取消检测）
    │
    ├── DefenseManager（防御/完美盾反）
    │
    └── AnimationController（驱动Animator，参数同步）
```

#### 战斗系统数据流

```
玩家按下攻击键
    │
    ▼
InputManager 检测到动作
    │
    ▼
FighterController 查询当前状态 → 判断能否攻击
    │
    ▼
攻击命中 → Hitbox 检测到 Hurtbox
    │
    ▼
DamageSystem.CalculateKnockback(攻击数据, 目标当前%)
    │
    ▼
目标 FighterController 进入 Knockback 状态
    │
    ▼
KnockbackSystem 应用物理速度（含DI/SDI输入影响）
    │
    ▼
目标碰触 BlastZone → 加命/丢命/重置
```

### 2.3 数据配置层 (Data)

所有角色/模式/舞台参数使用 **ScriptableObject** 配置，无需修改代码即可调整数值。

#### FighterData (ScriptableObject)

```csharp
public class FighterData : ScriptableObject
{
    [Header("基础属性")]
    public string fighterName;       // 角色名
    public float weight = 100f;      // 体重（影响击飞距离，越大越不易击飞）
    public float walkSpeed = 5f;     // 移动速度
    public float runSpeed = 8f;      // 冲刺速度
    public float airSpeed = 6f;      // 空中速度
    public float jumpForce = 12f;    // 跳跃力
    public int jumpCount = 2;        // 跳跃次数（大乱斗通常2段跳）

    [Header("攻击数据")]
    public AttackData[] attacks;     // 所有攻击动作配置
}
```

#### AttackData (可嵌套类)

```csharp
[System.Serializable]
public class AttackData
{
    public string attackName;        // 攻击名称
    public float damage;             // 伤害值
    public float knockbackAngle;     // 击飞角度 (0=水平, 90=垂直)
    public float knockbackBase;      // 基础击飞值
    public float knockbackGrowth;    // 击飞成长系数
    public float startupFrames;      // 前摇帧
    public float activeFrames;       // 判定帧
    public float recoveryFrames;     // 后摇帧
    public float shieldDamage;       // 护盾伤害
    public AudioClip hitSound;       // 命中音效
    public GameObject hitEffect;     // 命中特效
}
```

### 2.4 管理器层 (Manager)

| 管理器 | 单例 | 职责 |
|--------|------|------|
| `GameManager` | ✅ | 全局游戏状态、场景加载、玩家管理 |
| `MatchManager` | ❌(场景内) | 比赛规则执行、开局/暂停/结束 |
| `CameraManager` | ❌(场景内) | 摄像机跟踪多个目标，自适应缩放 |
| `ObjectPooler` | ✅ | 特效/弹丸/UI对象池 |
| `UIManager` | ✅ | UI面板管理、导航 |
