# 平台格斗游戏

## 一、单人模式模块

### 1.角色选择

玩家从一个角色列表中挑选自己要使用的斗士，确认后进入下一步。

### 2.地图选择

选择对战舞台，预览舞台外观，确认后进入规则设置。

### 3.游戏规则设置

设置比赛规则：模式（命数制/时间制）、具体参数、CPU 难度。

### 4.游戏内战斗

核心玩法：玩家操控角色与 CPU 对手在舞台上对战，直到分出胜负。

### 5.战斗系统

角色控制

地面、空中、必杀技攻击

防御、受击与击飞系统

命数与时间规则、重生系统

屏幕震动、特效、HUD

CPU AI状态机系统

## 二、多人游戏模块

### 1.角色选择

2~4 名玩家使用键盘分区 + 手柄在同一屏幕上对战，每名玩家从角色列表中挑选自己要使用的斗士，全部确认后进入下一步。

### 2.地图选择

选择对战舞台，预览舞台外观，确认后进入规则设置。

### 3.游戏规则设置

设置比赛规则：模式（命数制/时间制）、具体参数

#### 4.单人模式外新增功能

多设备识别

空位填补CPU，未连接玩家的位置自动填入 AI，可手动切换 玩家/CPU/空位

多人独立选人锁定，每个玩家在自己的槽位独立高亮、确认、锁定，互不干扰

4人位置随机生成

### 1.角色选择

### 2.地图选择

## 四、设置以及音效模块

### 1.按键设置

按键绑定修改、按键冲突检测、恢复默认

多设备独立配置

### 2.音频设置

音量滑块、静音开关、音量持久化

### 3.画面设置

全屏、窗口

### 2.游戏记录

## 六、比赛模式

## 七、关卡模式

难度选择、特殊规则选择、一定局数后有限时计时关卡
