# 项目概述

## 项目名称
**SuperSmashLike** — 基于Unity的类《任天堂明星大乱斗》平台格斗游戏

## 项目背景
《任天堂明星大乱斗》（Super Smash Bros.）是由任天堂发行的经典平台格斗游戏系列，以其独特的百分比击飞机制、丰富的角色阵容和易上手难精通的 对战体验闻名。本项目的目标是使用 **Unity 2022.3 LTS**，复刻大乱斗的核心战斗系统，并利用现有 Synty 系列美术资源 打造一个可玩的原型Demo。

## 技术栈

| 项目 | 说明 |
|------|------|
| 引擎 | Unity 2022.3.62f3 (LTS) |
| 渲染管线 | 内置渲染管线 (Built-In Render Pipeline) |
| 输入系统 | Unity Input System 1.14.2 |
| 脚本语言 | C# (.NET Standard 2.1) |
| 版本控制 | Git (推荐) |
| 美术资源 | Synty Polygon 系列、SimpleFarm、InterfaceFantasyWarriorHUD |
| 动画系统 | Unity Animator + 根运动 (Root Motion) |

## 毕业设计选题意义

### 理论意义
1. **平台格斗游戏系统研究**：深入分析大乱斗的百分比击飞公式、连段系统、防御/抓取循环等核心机制
2. **游戏框架设计**：探索面向对象+ScriptableObject混合架构在格斗游戏中的应用
3. **多人同屏技术**：研究4人同屏对战的摄像机管理、输入管理、碰撞检测

### 实践意义
1. 完整经历从架构设计→编码实现→资源整合→调优测试的游戏开发全流程
2. 掌握 Unity Input System、Animator 状态机、对象池等核心技术
3. 产出一份可直接运行的格斗游戏Demo，可用于展示/面试/参赛

## 核心玩法
- 2~4名玩家在同屏幕舞台上对战
- 通过攻击累积对手伤害百分比（0%~999%）
- 使用蓄力 Smash 攻击将对手击飞出屏幕边界
- 支持本地多手柄/键盘混用
- 经典大乱斗规则：命数制 + 时间制

## 参考游戏
- **Super Smash Bros. Ultimate**（主要参考）
- **Rivals of Aether**（像素风平台格斗）
- **Brawlhalla**（免费平台格斗）
