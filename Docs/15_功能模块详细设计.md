## 一、单人模式模块

单人模式 = 玩家 vs CPU。核心流程：**选角色 → 选地图 → 选规则 → 进入战斗**

### 1.1 角色选择

#### 功能描述
玩家从一个角色列表中挑选自己要使用的斗士，确认后进入下一步。

#### 交互流程
```
进入选人画面
    │
    ├── 显示角色网格（6角色 × 头像/名称）
    │       │
    │       ├── 玩家用方向键/摇杆 左右移动高亮
    │       ├── 按确认键（Enter/A）选择当前高亮角色
    │       └── 选中后角色头像放大，显示"已选择"标识
    │
    ├── 显示确认按钮（"确定，进入下一步"）
    │
    └── 玩家确认 → 锁定选择 → 进入地图选择
```

#### CPU AI 行为设计

AI 按状态机决策，每帧选择行为：

```csharp
// AI 状态枚举
enum AIState
{
    Approach,   // 接近对手
    Attack,     // 攻击（根据地面的空中选择招式）
    Defend,     // 防御/闪避
    Retreat,    // 后撤
    Recover,    // 回场（被击飞后回舞台）
}

// 难度参数化
[System.Serializable]
class AIDifficultyParams
{
    public float reactionTime = 0.2f;     // 反应延迟（秒）
    public float attackChance = 0.6f;     // 攻击倾向
    public float defendChance = 0.3f;     // 防御倾向
    public bool canPerfectParry = false;  // 能否完美盾反
    public bool canTrueCombo = false;     // 能否打真连段
    public float inputErrorRate = 0f;     // 输入失误率
}
```

| 难度 | reactionTime | attackChance | defendChance | canPerfectParry | canTrueCombo | inputErrorRate |
|------|-------------|-------------|-------------|----------------|-------------|---------------|
| 简单 | 0.5s | 0.4 | 0.2 | ❌ | ❌ | 30% |
| 普通 | 0.2s | 0.6 | 0.3 | ❌ | ✅ | 10% |
| 困难 | 0.1s | 0.7 | 0.4 | ✅ | ✅ | 0% |
| 疯狂 | 0.05s | 0.8 | 0.5 | ✅ | ✅ | 0%（预读输入） |

### 1.4.24 出招表

#### 功能描述

显示当前角色的全部招式列表、输入指令和帧数据，帮助玩家了解角色性能。

#### 输入逻辑

`FighterData` 已为每个角色预留 4 个必杀技数据槽（`specialNeutral` / `specialSide` / `specialUp` / `specialDown`），但 `InputManager` 中尚无方向键 + 必杀技键的组合判定逻辑。需新增：

1. **方向 + 必杀技组合判定** — 在 `InputManager` 中新增 `GetContextualSpecial()` 方法，根据当前左摇杆方向和是否空中选择对应的必杀技
2. **Cancel 到必杀技** — 攻击的可取消帧内 (`AttackData.canSpecialCancel`) 按必杀技键，自动取消到必杀技
3. **蓄力必杀技** — 按住必杀技键蓄力，松开释放增强版

```csharp
// InputManager.cs 新增
private void Update()
{
    // ... 原有逻辑 ...
    
    if (SpecialPressed)
    {
        AttackData special = GetContextualSpecial();
        if (special != null)
            fighterController.TryAttack(special);
        SpecialPressed = false;
    }
}

private AttackData GetContextualSpecial()
{
    if (fighterController.fighterData == null) return null;
    
    if (MoveInput.y > 0.5f) return fighterController.fighterData.specialUp;
    if (MoveInput.y < -0.5f) return fighterController.fighterData.specialDown;
    if (Mathf.Abs(MoveInput.x) > 0.5f) return fighterController.fighterData.specialSide;
    return fighterController.fighterData.specialNeutral;
}
```

#### 出招表 UI

| 展示位置 | 触发方式 | 内容 |
|---------|---------|------|
| **暂停菜单** | 战斗中按暂停 → 选择"出招表" | 当前角色的全部招式列表（含输入指令、伤害、击飞值） |
| **选人界面** | 选中角色后按 F1/Help 键 | 招式预览 + 角色特色说明 |

## 二、多人游戏模块

多人模式 = 2~4 名玩家（可混合 CPU）在同一台电脑上进行对战。

### 2.1 本地多人（同屏）

#### 功能描述
2~4 名玩家使用键盘分区 + 手柄在同一屏幕上对战。

#### 交互流程

```
进入多人选人画面
    │
    ├── 设备检测
    │       ├── 键盘 P1：WASD + 左手键位（自动存在）
    │       ├── 键盘 P2：方向键 + 小键盘（自动存在）
    │       ├── 手柄 P3：插入即识别（PlayerInputManager 自动检测）
    │       └── 手柄 P4：插入即识别
    │
    ├── 空位处理
    │       ├── 空位默认填充 CPU（难度 = 普通）
    │       └── 可手动切换 空位/CPU/等待加入
    │
    ├── 各自选角色（同一屏分 4 个槽各自操作）
    │       ├── P1/P2 用键盘各自选择
    │       ├── P3/P4 用手柄选择
    │       └── 每个玩家独立高亮+确认
    │
    ├── 各自确认锁定（每个玩家按各自确认键锁定）
    │
    └── 全部锁定 → 进入地图选择 → 规则设置 → 开始比赛
```

```csharp
public class TournamentData
{
    public int playerCount;                    // 4/8/16
    public int totalRounds;                    // 总轮次（4人=2轮, 8人=3轮, 16人=4轮）
    public List<BracketSlot> allSlots;         // 所有对阵槽位
    public int currentRound;                   // 当前进行到的轮次
    public List<PlayerSlot> participants;      // 参赛者列表
}

[System.Serializable]
public class BracketSlot
{
    public int slotID;                         // 槽位 ID
    public int round;                          // 第几轮（0=第一轮）
    public int matchIndex;                     // 该轮中的第几场
    public int? player1ID;                     // 玩家1的参赛者索引（null=待定）
    public int? player2ID;                     // 玩家2的参赛者索引
    public int? winnerID;                      // 胜者索引（null=未决出）
    public int? loserID;                       // 败者索引（null=未决出）
    public int? nextSlotID;                    // 胜者进入的下一槽位 ID
    public bool isCompleted;                   // 是否已完成
}

[System.Serializable]
public class PlayerSlot
{
    public int id;                             // 参赛者 ID（0~15）
    public string name;                        // 显示名称
    public bool isCPU;                         // 是否 CPU
    public AILevel cpuDifficulty;              // CPU 难度

}
```

```csharp
// FighterController.cs 添加
public int teamID = -1;  // -1=无队伍, 0=红队, 1=蓝队

// ApplyDamage() 中添加团队判断：
if (GameManager.Instance.gameSettings.enableTeamMode
    && attacker.teamID == this.teamID
    && !GameManager.Instance.gameSettings.enableFriendlyFire)
```

## 七、闯关模式模块

### 7.1 经典闯关（Classic Mode）

#### 功能描述
《大乱斗》经典模式。玩家选择一名角色，连续挑战 8~10 个关卡，每关对手越来越强，最终挑战 Boss。中途有奖励关和恢复机会。

#### 交互流程

```
进入闯关模式
    │
    ├── 选角色（只能选一个角色，全程使用）
    ├── 选难度（简单 / 普通 / 困难）
    │
    ├── 开始闯关（共 8+2 关）
    │
    ├── 第1关：杂鱼战（1 vs 1，CPU-简单）
    │       └── 胜利 → 恢复少量伤害（-10%） + 显示下一关预告
    │
    ├── 第2关：双人战（1 vs 2，两个 CPU-简单）
    │       └── 胜利 → 恢复 + 奖励（命数+1）
    │
    ├── 第3关：标准战（1 vs 1，CPU-普通）
    │       └── 胜利 → 恢复
    │
    ├── 第4关：限时挑战（60秒内尽可能造成高伤害）
    │       └── 胜利条件：造成 80%+ 伤害
    │       └── 奖励：伤害越高→下一关初始伤害越低
    │
    ├── 第5关：标准战（1 vs 1，CPU-普通+）
    │       └── 胜利 → 恢复
    │
    ├── 第6关：组队战（1 vs 2，CPU-普通）
    │       └── 胜利 → 恢复
    │
    ├── 第7关：标准战（1 vs 1，CPU-困难）
    │       └── 胜利 → 恢复
    │
    ├── 第8关：乱战（1 vs 3，CPU-普通×3）
    │       └── 胜利 → 恢复 + 命数+1
    │
    ├── 第9关：标准战（1 vs 1，CPU-困难+）
    │       └── 胜利 → 满血恢复
    │
    ├── 第10关：Boss战
    │       ├── Boss 角色（特殊大体重角色，如 ElementalGolem）
    │       ├── Boss 属性增强：体重×1.5、攻击力×1.3、击飞抗性×1.5
    │       ├── Boss 两条命（击杀一次后复活+增强）
    │       └── 击败 Boss → 通关！
    │
    └── 结算
            ├── 通关时间
            ├── 总击杀数
            ├── 总受伤量
            ├── 关卡完成度（全关卡评价 S/A/B/C）
            ├── 总分 = 基础分 × 难度系数
            └── 返回闯关菜单 / 重新挑战 / 退出
```

#### 关卡配置数据结构

```csharp
[System.Serializable]
public class ClassicStageConfig
{
    public string stageName;                           // "第1关：杂鱼战"
    public StageType stageType;                        // 关卡类型
    public int opponentCount;                          // 对手数量（1~3）
    public AILevel cpuDifficulty;                      // CPU 难度
    public string[] opponentCharacterNames;            // 对手角色名（随机留空）
    public bool hasSpecialRule;                        // 是否有特殊规则
    public SpecialRule specialRule;                    // 特殊规则
    public float rewardHealPercent;                    // 胜利后恢复百分比
    public int extraStockReward;                       // 额外命数奖励

    public enum StageType
    {
        Standard1v1,       // 标准 1v1
        Standard1v2,       // 1v2 组队战
        Standard1v3,       // 1v3 乱战
        TimeAttack,        // 限时挑战（规定时间造成足够伤害）
        Boss,              // Boss 战
    }

    public enum SpecialRule
    {
        None,              // 无特殊规则
        HighDamage,        // 伤害×1.5
        LowGravity,        // 低重力
        SpeedUp,           // 全体加速
        GiantCPU,          // CPU 体型变大
        MetalCPU,          // CPU 金属化（减击飞）
    }

    public enum AILevel
    {
        Easy,
        Normal,
        Hard,
        HardPlus,
        Boss,
    }
}
```
